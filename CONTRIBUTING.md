# Contributing Guidelines

Thank you for your interest in contributing to the **E-Commerce Growth & Review Intelligence Engine**!

## Development Workflow
1. Fork the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Implement your changes following the existing clean code principles.
3. Ensure all tests pass:
   ```bash
   npm run test
   ```
4. Commit your changes with conventional commit messages (`feat: add shipping defect cluster analyzer`).
5. Open a Pull Request.

## Code of Conduct
Please be respectful, collaborative, and constructive in all community interactions.
